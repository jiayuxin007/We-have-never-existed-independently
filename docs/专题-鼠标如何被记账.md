# 专题：鼠标和键盘如何被记账

业力专题讲公式。本篇只讲 **账本从哪来**：哪一种手算数、哪一种不算、面板 Action 行为什么和最终道不是一回事。

文件：`app/karma/interaction-collector.js`。从雪花点击 `start()` 到进度条 100% `stop()`。之后再晃鼠标也不进 `finalizeSession`。

---

## 1. 为什么要单独记账

归道有两味：盘面时间、这一双手。盘面是币安推的。手必须程序自己听。浏览器会把「按下、移动、松开、滚轮、点击」变成事件。采集器挂在 `document` 上听这些事件（不是 `window`），累加几个数字，最后打包成 `getSummary()`。

它**不**判断你进哪一道。判断在算法里。它只负责当一个诚实的秤。

---

## 2. 秤上有哪些刻度

| 字段 | 人话 | 怎样才加一格 |
|---|---|---|
| clickCount | 点了多少下 | 左键 click |
| moveDistance | 指针走过的像素路 | 移动；**房屋上的看不算** |
| scrollDelta | 页面本身滚了多少 | 极少用，全屏页几乎不滚 |
| wheelDelta | 滚轮拧了多少 | **房屋画布上的滚轮只显示 Look，不加这个数**（所以识/名色缩放不进混乱）。房屋段 `#houseLayer` 铺满且接收点击，台词/面板点不穿，滚轮几乎总是落在房屋上。只有房屋藏起来时（经文、触点球）滚在特效或文字上才累加 |
| dragCount / Distance / Duration | 按住拖 | 移动超过约 8 像素才算一次拖 |
| dwellSeconds | 从 start 到现在过了几秒 | 时间自己走 |

面板 Action 是另一套**瞬时标签**：Stop、Move、Look、Drag、Scroll、Left-click、按键。停手约 0.9 秒回到 Stop。标签给观众看「系统在监视你」，**不代入** \(U_k\) 公式。不要看见自己一直 Stop 就以为一定进饿鬼。

---

## 3. Look：转房子故意不算乱

若事件目标在 `#houseLayer` 里面（你在房屋画布上拖、转、拧），这次指针会话标成 `lookOnly`：

- 不计入 dragCount / dragDistance / dragDuration
- 不计入 moveDistance
- Action 显示 Look

原因：识和名色的提示就是 Hold and drag、Scroll to scale。若这些进 chaos，几乎每个认真看房子的人都会被推进畜生。制作上把「观看」和「躁动」分开。

房屋可见时整层铺满屏幕（`pointer-events: auto`）。台词、提示、仪表都是 `pointer-events: none`，十字光标也不接事件，所以**不能**靠「点在字上 / 点在面板上」躲开 Look。取那段面板淡出，与鼠标账无关。

房屋藏着时（经文、触点球）没有这层，拖和滚按普通 Move/Drag/Scroll 进账。

拖的判定：位移平方 > 64，也就是大约 8 像素。手抖一下不算拖。

---

## 4. 前 8 次点击是仪式

算法里 `ritualClicks = 8`。采集器是**点完光点之后**才 `start()` 的，开场那一下**不算**进 `clickCount`。之后过关大约是：奇点 1 次 + 六入 6 次，以及你若点击跳过经文再加 1 次。不跳过经文时过关点击大约 7 次，仍不超过 8。第 9 次起才进 `extraClicks`，才抬高活跃和躁。

所以：认真把六入点完的人，不会仅仅因为点了 8 下就被当成地狱。你若在触、受、爱再狂点，那些才算。

饿鬼生分里有一项用**全部** clickCount，不是 extra：`(1-min(1,clicks))`。奇点已经点过一次，这项在正式流程里几乎总是 0。也就是说：**手很难把人送进饿鬼**，饿鬼要靠行情把时间堆在那一栏。改这个政策，去业力专题第 8 节，不要改采集器。

---

## 5. 键盘

采集器会把按键记成 Action `INPUT:R` 之类，方便面板闪一下。**得分公式没有键盘项。** 饿鬼按 R 重置粒子，只影响画面层数，不加业力分数。不要宣传「按 R 会加重业」成算法事实——提示文案是诗，账本没这一栏。

---

## 6. 和导演的时间对齐

`main.js` 在雪花回调里 `INTERACTION_COLLECTOR.start()`，与 `MarketTicker.start()` 同一拍。调试 `?debug=1&stage=7` 跳进受时，`main.js` 仍会 start 采集（stage≥2）。从 7 开始的会话更短，`dwell` 小，手偏好和完整走完一场不可比。做权重实验时要固定同一入口。

`stop()` 在进度条走到 100% 的那一帧，与断 WS、`finalizeSession` 一起。停完后 summary 冻结。Begin again 跳到无查询参数的 pathname，秤从零开始。

调试若 `?path=` 或 `?debug=1&stage=11` **跳过了进度条**，采集会 start 但不会 stop；那次进道不走 `finalizeSession`，不能拿来当完整一场的业力结果。
