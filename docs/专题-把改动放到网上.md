# 专题：把改动放到网上

本地能看见新台词，观众打开 GitHub Pages 仍是旧的——多半不是「没保存」，而是没推上去，或推了但忘了给 `?v=` 加一。

不会用命令行也可以。本仓库已经挂在 GitHub：  
https://github.com/jiayuxin007/We-have-never-existed-independently  
线上：https://jiayuxin007.github.io/We-have-never-existed-independently/

先会改字、会本地预览：[从零在电脑上打开](./专题-从零在电脑上打开.md)、[屏幕上看到什么](./专题-屏幕上看到什么.md)。缓存细节：[发布调试与排障](./专题-发布调试与排障.md)。

---

## 1. 两套地址，别搞混

| 你打开的 | 改的是谁 |
|---|---|
| `http://localhost:8080/app/index.html` | 你硬盘上的文件，关掉 bat 窗口就没了 |
| `https://jiayuxin007.github.io/...` | GitHub 上的副本，必须 **push 到 `main` 分支** 才会更新 |

改完先在 localhost 看对，再推。不要只刷新线上链接指望它变成你刚改的字。

---

## 2. 推之前先做这两件事

1. 若改了某个 `.js`：打开 `app/index.html`，Ctrl+F 搜文件名，把 `?v=` 后面数字加一。那一行如果根本没有 `?v=`（例如 `chart.config.js`、`crosshair-cursor.js`），先写成 `?v=1`。只改 `index.html` 里的字（金刚经、终章）则不必。若改的是 `reference/` 里某份 `*-embed.js`：去 `effect-registry.js` 的 `EFFECT_DEFS.scripts` 给那条 URL 加/改 `?v=`，再 bump `effect-registry.js` 自己在 `index.html` 里的数字。只改 embed、不改 URL，网上仍可能是旧特效。
2. 不要把调试链接写进给观众的二维码。`?path=`、`?debug=1`、`?market=mock` 都是制作后门。mock 只给展场网挂时的**备用**链接。

不要提交密码、`.env`、随便拷来的未授权字体到公开仓库。版权见 [素材版权与授权](./专题-素材版权与授权.md)。

---

## 3. 用 GitHub Desktop（不会命令也可以）

1. 安装 [GitHub Desktop](https://desktop.github.com/)，用 GitHub 账号登录。
2. File → Add local repository，选这个项目文件夹（能看见 `app` 和 `docs` 的那一层）。
3. 左侧会列出改过的文件。看一眼有没有不该上传的东西。
4. 左下角 Summary 写一句人话，例如「改终章那句英文」。
5. Commit to main，然后 **Push origin**。
6. 等一两分钟。用**无痕窗口**打开线上地址（Ctrl+Shift+N），不要用展场昨天开着的标签。

第一次 Push 若要登录或授权，按窗口提示走。推不上去时把报错原文发给会 Git 的人，不要自己点 Force push。

---

## 4. 用命令也可以（可选）

在项目文件夹的 PowerShell：

```text
git status
git add app/index.html app/config/stages.config.js
git commit -m "Update subtitle copy."
git push origin main
```

只 `add` 你改过的文件。不要 `git add .` 把根目录误放的 `fonts/`、临时 mp3 一并送上去，除非你确定要。

不要 `git push --force`。不要改 `git config`。

---

## 5. 推了还是旧的

按这个顺序：

1. GitHub 网页上打开对应文件，看内容是不是新的。若 GitHub 上仍是旧句，说明没 push 成功。
2. 若 GitHub 上已是新句，看 `app/index.html` 里这个 js 的 `?v=` 有没有变。没变则观众浏览器还拿旧缓存。
3. 无痕窗口再开 Pages。GitHub Pages 有时要等一两分钟。
4. 大模型 `less_25mb.glb`：在 GitHub 网页上应能看到体积。若克隆时漏了这个文件，识会一直转圈。

---

## 6. 和开展的关系

观众**不需要** Python、Git、bat。他们只打开 https。  
你的工作是：localhost 验收 → bump `?v=` → push `main` → 无痕打开 https 再走一遍。

把改动「只存在你的电脑里」带去展场，等于没改。
