# 专题：右上角仪表

经文结束后出现的「業力計算系統」。它是**显示器**，不是判决书。最终进哪一道，观众要到第 11 段全屏 HUD 才看见。

文件：`app/ui/karma-data-panel.js`、`karma-pie-chart.js`、`karma-bar-chart.js`、`datav-border-box-1.js`、`config/chart.config.js`、`config/realm-assets.config.js`。  
算法：[业力计算系统](./业力计算系统.md)。壳和出现时机：[开场字幕与界面](./专题-开场字幕与界面.md)。

---

## 1. 你看见的每一块

| 位置 | 意思 | 不是什么 |
|---|---|---|
| 左上 logo + 英文道名 | **这一包行情刚抽中的道**（Current Tendencies） | 不是最终道，每来一包都可能换。PNG 404 时显示道名首字母 |
| 横线 `line.webm` | 装饰；加载失败换成 CSS 细条 |  |
| Action | 此刻手在干什么：Stop / Move / Look / Drag… | 不进得分公式 |
| Volatility / Turnover / Stability | 这一包算出来的 Vol、Turn、Stab | Turn 在面板上乘了 100 加 `%`，算法内部用未乘的比 |
| MARKET CAP | 真盘：\(19900000\times\) 最新价。假盘：写死 `1.2e12`，**不是**流通量×价 | 不是交易所官方市值接口 |
| 24h change % | 币安字段 `P` |  |
| 饼图中心大字 | 从点光点到现在过了多少秒，例如 `42s` |  |
| 饼图中心下面 `live` | 写死的字，表示还在收行情 | 结算后观众已经看不见这块板 |
| 饼 / 条的长短 | 各道**市场停留时间**占比 \(T_k/T_{\mathrm{tot}}\) | **不含** 0.45×鼠标；所以饼最高柱不必等于最终道 |

Ether_Frictionless 这类代号写在 `PATH_META.code` 里，主面板不画图例，观众看不到。

约每 5 秒（`logoPlayIntervalMs`）跑一轮：边框动画会再播；若 `line.webm` 在，横线从头播。Logo 已改成静态 PNG，这一轮**不会**让图标重新动一遍。道名仍是**当前这一包**的道，不会轮播六道。

`chart.config.js` 的 `legendLayout: 'pills'` **没有人读**。主面板不画图例；饼预览页自己写了一套 pills，改配置这项不会动正赛。

## 2. 何时出现、何时消失

- 开场、经文：没有。
- `sutra:complete` 之后 `show()`。
- 进「取」（`house-qu`）开始 3 秒淡出（`FADE_OUT_MS=3000`）。
- 进度条 `karma:finalize-start` 再 `hide()`（保险）。
- 六道 HUD 出现时再 hide 一次。

`?panel=0` 整场不建这块板。`?chart=arc|orbital|whisper|donut` 可换饼的画法；正赛默认 `chart.config.js` 的 `orbital`。

---

## 3. 假盘时数字从哪来

`?market=mock` 不连币安。大约每 1.5～5 秒塞一包：价在 60000～61000 晃、`MC` 写死 `1.2e12`（**不是**流通量×价）、涨跌 ±5%。饼会动，但那不是当天真盘，不能拿去讲「共业」。

真盘断开**不会重连**，数字停在最后一包。见 [展场与设备限制](./专题-展场与设备限制.md)。

## 4. 想改颜色或英文道名

- 饼/条的色和英文名：`karma-pie-chart.js` 的 `PATH_META`（天金、人蓝、修红、畜绿、饿紫、狱橙）。HUD 道名优先不读这里，读 `realm-assets`。
- 面板上 Current Tendencies 的英文：优先 `realm-assets.config.js` 的 `realm`。
- 边框折线：`datav-border-box-1.js`，颜色 `#8ECAE6` / `#289786`。
- 改完 bump 对应 `?v=`。不要在预览页 `pie-chart-preview.html` 里改完以为正赛变了。
