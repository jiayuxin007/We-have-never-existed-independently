# 专题：房屋点云

文件：`app/house/house-model-stage.js`。  
模型：`assets/models/less_25mb.glb`。  
依赖：Three r128、GLTFLoader、OrbitControls、同页的 `AeGlow`。

本篇只讲这条 r128 管线。六道 WebGL 不走这里。

---

## 1. 场景

- `WebGLRenderer({ antialias: true, alpha: true })`，清屏透明，星空 video 在底下。
- `pixelRatio ≤ 2`，`sRGBEncoding`，`ACESFilmicToneMapping` 曝光 1.2。
- 环境光 0.55 + 主方向光 0.95 + 冷补光 0.28。
- 相机 60°；OrbitControls 阻尼 0.05，禁 pan。**爱、取**调用 `lockAiControls()`：控件整段关掉（不能转、不能滚）。生 / 老死会 `unlockAiControls()`。
- 点色 `COL_HOUSE = 0x3A6D75`，冲击/涟漪高亮 `#FF7A28`。

开场 `prefetchModel()`：`fetch` GLB 为 ArrayBuffer，`GLTFLoader.parse`。避免「识」才开始下 20MB+。Registry 还 patch 了 r128 的 FileLoader / ImageBitmapLoader，让 `blob:` 预取能用 XHR 读。

---

## 2. 网格变成点

遍历 GLTF `Mesh`，clone 材质。主网格 `position` 拷入 `originalPositions`（`Float32Array`，每三点一顶点）。新建 `THREE.Points`：

- geometry：`position`（dynamic）+ `aSizeScale`
- `ShaderMaterial`，`transparent`，`depthWrite: false`
- `points.rotation.x = π/2` 对齐这套 GLB 轴向
- 包围盒中心挪到原点

之后多数 mode **不再显示三角面**，只画点。识是例外：**整段都是实体 mesh**（前 2.4s 放大，之后 `applyHold()` 关点、留网格）。Glow 在识段关闭。

---

## 3. 点云着色器

CPU 改 uniform 和有时整份 `position.array`；GPU 算尺寸、丢弃、发光。

透视缩放：

\[
\mathrm{gl\_PointSize}
= uPointSize \times \frac{300}{\mathrm{dist}} \times aSizeScale \times (1+\text{加成})
\]

`uPointSize` 默认 `0.012`，`dist` 为相机空间距离。

**切片（名色）：** 世界 \(y\) 与切割面 \(C+噪声\) 比较，点在面之上才保留；近切边 `sliceRim` 加尺寸和亮边。

**冲击波（六入，最多 6 路）：** 原点 \(W_i\)、年龄 \(A_i\)。着色器里波前半径是 \(A_i\cdot uWaveSpeed\)，带宽是 `uWaveWidth`：

\[
\mathrm{band}_i=\bigl(1-\mathrm{smoothstep}(0,w,\lvert\|x-W_i\|-A_i v\rvert)\bigr)
\cdot\bigl(1-\mathrm{smoothstep}(0,1.45,A_i)\bigr)
\]

构造时 uniform 默认 \(v=8\)、\(w=0.42\)、踢 \(0.22\)，**六入点亮时会被改掉**。`ensureShockWaveParams()` 按房屋包围盒最大边 \(D\) 写成：波速 \(\max(D\cdot 1.15,\,4.5)\)、带宽 \(\max(D\cdot 0.045,\,0.22)\)、踢 \(\max(0.16,\,D\cdot 0.022)\)。不要按文件里那三个初始数字调观感。

沿 \(\mathrm{normalize}(x-W_i)\) 位移 `uShockKick`。

**鼠标涟漪（触）：** 距离 \(d\)、半径 \(R\)：

\[
\mathrm{ripple}=\min\bigl(1,\;0.72\cdot\mathrm{halo}+\mathrm{core}\bigr)\cdot uRipple
\]

halo / core 为两档 `smoothstep`。ripple 加尺寸，片元把颜色混向橙。

**全息带：** `uHoloOn` 时按世界 Y 做一条噪声抖动的亮带（受的苦态等会用到相关外观，位移仍以 CPU 为主）。

片元：圆点

\[
\alpha=\bigl(1-\mathrm{smoothstep}(0.2,1,\,2\|\mathrm{gl\_PointCoord}-0.5\|)\bigr)\cdot vGlow\cdot uPointAlpha
\]

## 4. 名色溶解（mesh 的 onBeforeCompile）

实体房屋不能用 Points 切片。在 MeshStandard 的 `#include <map_fragment>` 后插入条纹噪声 \(n\)：

\[
n < uDissolve - 0.55\cdot\mathrm{edgeWidth} \Rightarrow \mathrm{discard}
\]

前沿混入橙 `(1.0, 0.48, 0.16)`。`customProgramCacheKey = 'mingse-hstripe-dissolve-v2'`。

时间轴（段长来自分镜 `durationMs`，正赛 9.6s）：0–0.8s hold 实体 → dual（dissolve 与点云 `uSliceCut` 上扫）→ settle 1.0s。dual 长度是 \(\max(3.5,\;\text{段长}-0.8-1.0)\)，**正赛约 7.8s**。`MINGSE_DUAL_S=6.4` 只在没传入 `durationMs` 时参与后备总长，主流程用不到这个 6.4。

## 5. 各 mode 的 CPU 算法

入口：`enterStageMode(stageKey, { durationMs, vedanaKind, onMouseMove })`。每帧 `tick*`。

### expand（识）

前 `INTRO_EXPAND_S=2.4` 秒：

\[
s=\mathrm{easeInOut}(t/2.4),\quad \mathrm{scale}=(s,s,s)
\]

之后 `applyHold()` 实体、关点。Idle：慢转、呼吸、dolly。**Glow 关闭。**

### particleize（名色）

CPU/着色器时间轴见第 4 节（hold → dual 切片+溶网格 → settle）。正赛 dual 跟 9.6s 段长走，不是常量 6.4s。

### six-circles（六入）

点云稳定。模型空间 6 节点 → 每帧投影屏幕 → 点击命中：对应 `uA_i=0` 起波，`NoteAudio.playNote(i)`，发 `liuru:node`。命中半径约 **42px**（相对节点投影）；按下后拖超过约 **6px** 当误触，不点亮。点亮第 6 个后再等约 **480ms** 发一次 `liuru:complete`（不是发六次 complete）。

音高 Hz：\(261.63, 293.66, 329.63, 392, 440, 523.25\)（C4 五声）。合成细节（低八度、滤波滑动）见 [声音专题](./专题-声音与必须存在的文件.md)。

### chu（触）

\[
\mathrm{amp}=\mathrm{peak}\,e^{-d\cdot\mathrm{fall}}+\mathrm{base}
\]
\[
x=x_0+\sin(18t+20x_0)\cdot\mathrm{amp},\quad
y=y_0+\cos(16t+20y_0)\cdot\mathrm{amp},\quad
z=z_0+\sin(17t+20z_0)\cdot\mathrm{amp}
\]

`uRipple=1`，`uMouse` 跟指针世界坐标（着色器里再加一圈靠近鼠标的亮边）。CPU 抖动在 `applyDustTremor`。

### shou（受）

包络：0–1s 余震 → 1–6s 主段 → 6–8s 阻尼拉回原位。之后约 1.6s 停在阻尼终点（分镜仍是 9.6s）。`vedanaKind`：

| kind | 位移 |
|---|---|
| dukha | \(R=\mathrm{fract}((t-1)\cdot0.62)\cdot D\cdot1.25\)，锯齿 `fract(2.6d-11t)` 沿径向推 + jitter |
| sukha | 更慢正弦环 \(R=\mathrm{fract}((t-1)\cdot0.28)\cdot D\cdot1.15\)，向心吸引 \(0.18k\) |
| upeksha | \(x\leftarrow x(1+0.02k\sin(\cdots))\) 呼吸 |

\(D=\) 房屋最大边。接触点 `computeShouContact()`。

### ai / qu（爱 / 取）

对齐 `reference/sketch2812705`。屏幕空间球半径约视口短边 32%。第 \(i\) 点二维家：

\[
x_h=\sin(i+\theta)\sin(i^2)\,r,\qquad y_h=\cos(i^2)\,r
\]

`AI_ATTRACTION=0.045`，排斥半径 \(r\cdot90/250\)，强度 `28*(r/250)`，阻尼 \(0.76^{\Delta t/0.016}\)（frameScale 限制在 0.5–2.5）。爱：房屋点 lerp 到球面并锁相机、上抬。取：已在球面，鼠标推灰后弹回。进度条阶段房屋仍停在 `qu`。

### phase（生）

`writePhaseOffset`：原位置加编织波。振幅跟鼠标 NDC.x，每帧以 `delta*6` 靠近目标。前 0.75s smootherstep：\(u=3u^2-2u^3\)。

### fade（老死）

每点 \(\delta_i\sim U(0,5.4)\) 秒后沿局部 up 抬 \(0.28D\)、水平漂 \(0.1D\)，`aSizeScale` 缩小。若 `fadeFromPhase`，叠未收完的 phase，避免硬切。

## 6. 渲染顺序与 Glow

`aeGlowAllowed()`：`suspended` / `expand` / `ring-flow` 为关；否则要求点云 alpha 足够。mesh 与点同时在时：先关 glow 画 mesh，再 glow 画点。

主循环：`requestAnimationFrame` → `clock.getDelta()` → 按 `mode` 调对应 `tick*` → `controls.update()` → `renderHouse()`。`animTime` 累加后喂给 shader `uTime`。不要在 tick 里 `new` 大数组，`originalPositions` / `randomOffsets` / 爱的 `aiPosX` 都是进段时分配、反复写。

指针：`pointermove` 更新 NDC 与世界 `uMouse`；六入在 canvas 上 `pointerdown/up` 做拾取。`onMouseMoveCb` 可转给外层（主流程十字光标不靠这个）。

`suspend({ keepVisible })` 停 rAF、关控件，供六道占满屏幕。`exitStage` 拆 renderer。

## 8. 完全不懂三维时，只要记住这些

**顶点：** 模型表面上的一个点的坐标 (x,y,z)。房屋有成千上万个。程序把它们存成一长串数字 `originalPositions`。以后无论怎么抖、怎么聚成球，都是在改这串数字的「当前值」，需要时再拷回原值。

**网格 vs 点云：** 网格是三角形拼成的墙，能贴图。点云是每个顶点画一个圆点，没有墙。识先出网格，名色把墙溶掉露出点，后面几乎全是点。

**着色器：** 一小段在显卡上跑的程序。CPU 若每帧对几万个点算发光圆，会卡。所以「点有多大、圆不圆、切不切开」放进着色器，CPU 只拨几个旋钮（uniform）：鼠标在哪、波传到第几秒、透明度。

**为什么爱会锁镜头：** 球面算法把点投在「对着相机的一张饼」上。若这时还允许 OrbitControls 乱转，家位置和鼠标射线会对不上，球会散。所以爱/取关掉旋转。

**调试某一身法：** `http://localhost:8080/app/index.html?debug=1&stage=8` 从爱开始。名色是 4，触是 6，受是 7，生是 12。受的苦态再加 `&vedana=dukha`。

**改颜色：** 只改 `COL_HOUSE` 不会自动改饿鬼环，饿鬼环色是 registry 读 `getCloudColorRgb()` 再传入的，一般跟着房屋走。辉光阈值太低会把星空也咬亮，那时去改 AeGlow 而不是把点改暗。

名色「溶边」的橙色写在 `onBeforeCompile` 的片元字符串里，不是 `COL_HOUSE`。你把点改青了，溶解前沿仍可能是橙，这是故意的切边高光。要换切边色，得改那段 `vec3(1.0, 0.48, 0.16)`，并 bump 房屋脚本。

爱的球面公式里有 `sin(i²)`，点的编号 i 很大时，普通小数会失去精度，看起来像随机洒在圆周上——这是参考 sketch 的味道，不是 bug。不要为了「更圆」去改成均匀球面，那会变成另一件作品。取和爱共用这套力，只改 `AI_REPEL_STRENGTH` 两段一起变。进度条那 7 秒房屋仍停在取，观众还在推灰，这些推会计入鼠标账，所以最后 7 秒不是纯过场。
