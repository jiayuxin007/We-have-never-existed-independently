# 专题：发布调试与排障

对应：`app/index.html` 的 `?v=`、`app/main.js` 的 URL 参数、GitHub Pages、本地 `http.server`。

展场机器、键鼠、显卡、网络、隐私：[展场与设备限制](./专题-展场与设备限制.md)。  
改完怎么点选预览页：[预览页与验收](./专题-预览页与验收.md)。

---

## 1. 本地

```bash
cd D:\NewProject
python -m http.server 8080
```

打开 `http://localhost:8080/app/index.html`。不要双击文件。Windows 防火墙第一次可能问网络，选专用网络即可。

GLB、MP4、TTF、MP3 都在 `assets/`。克隆后若房屋永不出现：看 Network 里 `less_25mb.glb` 是不是 404 或被 Git 截断。

## 2. GitHub Pages

仓库静态站。根 `index.html`：

```js
location.replace('app/index.html' + location.search + location.hash)
```

观众带的 `?debug=1` 会传到 app。正式链接不要带 debug。

GitHub 仓库 Settings → Pages：Source 选 **Deploy from a branch**，分支 `main`，文件夹 **`/`（根）**。不要选 `/docs`——文档是给人读的 Markdown，不能当网站根。仓库里**没有** GitHub Actions 工作流，也没有单元测试。

推送 `main` 后 Pages 有一两分钟延迟。浏览器还可能缓存 JS。所以每个会改的脚本在 `app/index.html` 写成：

```html
<script src="house/house-model-stage.js?v=120"></script>
```

**改了哪个文件，就把对应那一行的数字加一。** 只改 `config/stages.config.js` 却忘了 bump `stages.config.js?v=`，线上台词还是旧的。这是本项目最常见的「我明明推了」问题。

有几条 `<script>` **现在没有** `?v=`：`six-realms.config.js`、`chart.config.js`、`event-bus.js`、`bg-video-controller.js`、`crosshair-cursor.js`、`datav-border-box-1.js`。改这些文件时要**先补上** `?v=1`（或把已有数字加一），否则 Pages 仍可能拿缓存。`six-realms.config.js` 主流程没人读，改了也看不见；`chart.config.js` 会改饼的画法，漏 bump 会以为没改成。

六道 / 触点球的 embed **不在** `index.html` 里，而在 `effect-registry.js` 的 `EFFECT_DEFS.scripts`。加载是 `fetch` 源码再插入，浏览器仍按 URL 缓存。当前**没有** `?v=` 的：`noise-flow-field-embed.js`、`the-spirit-embed.js`、`particle-love-embed.js`（以及未挂主流程的 `mouse-black-hole-embed.js`）。已经有的：`repel-particles-embed.js?v=4`、`constraint-particles-embed.js?v=3`、`hyper-mix-embed.js?v=2`、`particle-ring-embed.js?v=2`。改某一份 embed 时：给那条 URL 加上或加大 `?v=`，并且 bump `effect-registry.js?v=`（否则新数组进不了页面）。**只 bump registry、embed 的 URL 一字未改，fetch 仍可能拿到旧文件。**

CDN 拆成两家：`three.min.js` 和 p5 走 **cdnjs**；房屋用的 GLTFLoader、OrbitControls 走 **jsDelivr**。墙了一家就会挂房屋（哪怕另一家通）。旧 Three 在 `reference/` 是本地的，人道等仍可能出。完全离线需要把 r128、p5 也改成本地，当前未做。

币安 WS 被墙：饼图不长、归道缺市场项。用 `?market=mock` 喂假 tick，或接受只靠鼠标 / 默认人道。

## 3. 调试 URL

`main.js` → `parseDebugParams()`。

| 参数 | 作用 |
|---|---|
| `debug=1&stage=N` | 从第 N 段开。`stage` **必须**配 `debug=1`，光写 `?stage=11` 无效 |
| `path=egui` | 强制道；可用中文别名 天/人/修罗/畜/饿鬼/地狱。`path` **不必**配 `debug=1`，单独出现也会跳到 Stage 11 |
| `vedana=dukha\|sukha\|upeksha` | 强制受 |
| `market=mock` | 不连币安，本地假 tick |
| `panel=0` | 不建右上角仪表（`main.js` 读字符串 `'0'`） |
| `chart=orbital\|arc\|whisper\|donut` | 饼图变体；正赛默认 orbital |

`path` 无 `stage` 时会自动跳到 11。`__PATH_OVERRIDE__` / `__VEDANA_OVERRIDE__` 写在 window 上，导演 `peekPathId` 优先读。

跳段时 `main.js` 的额外行为（容易测错）：

| 你打开的地址 | 实际还会做什么 |
|---|---|
| `?debug=1&stage=0` | 导演把 Stage 0 当普通段跑，**不等雪花点击**（开场 click 不走 BlockingGate）。不要用这个测开场 |
| `?debug=1&stage=1` | 藏开场、播 BGM；**不** start 采集和行情（门槛是 `startIndex >= 2`） |
| `?debug=1&stage=N` 且 N≥2 | start 采集 + 行情；N>0 会 `BgmController.startLoop()`（浏览器可能仍拦自动播放）。**不会**走雪花那次 `NoteAudio.unlock()`（导演里的 `onSessionStart` 也从未被调用）。六入第一次点击本身是手势，通常仍能出点声音 |
| 跳到 11 或 `?path=egui`（跳过 10） | 采集会 start，但没有进度条，**不会 stop / finalize**。进哪一道用 `peekPathId`（强制 path 或偷看），不是完整一场的结算 |

**Begin again** 会跳到 `location.pathname`，上面这些参数全部消失。测 mock / 强制道时不要用按钮当「再来一次同条件」，应手动再打开带参数的地址。

实验室页（不进主 `index.html`）：`app/preview/*.html`、`app/iris-preview.html`。用来单看 Glow、名色、六道切生、饼图。不要把 preview 链接写进正式入口。

## 4. 故障表

| 现象 | 原因与处理 |
|---|---|
| 双击 HTML 黑、没房子 | `file://`。改用 localhost |
| 识一直转圈 | GLB 404 / 体积没推上 Pages |
| 天道全黑无报错 | `reference/particle-love/images/logo.png` 404 |
| 畜生 throw / 白屏 | 缺 `.footer` 桩或 hash 未在脚本执行前写好 |
| 人道之后房屋也坏 | dispose 前就把 THREE 拨回 r128；查 holdCount |
| 改 JS 没变化 | 未 bump `?v=`；无痕或强刷 |
| 饼图不动 | WS 被墙，或连上后断开。**没有自动重连**，要刷新页面 |
| Begin again 后假盘没了 | 按钮清掉 `?market=mock`，第二次去连真币安 |
| 转模型进畜生 | Look 应排除；检查是否点在 `#houseLayer` 外拖 |
| 后台标签特效像死 | 浏览器暂停 rAF，回到前台即可 |
| 字体变系统衬线 | TTF 未加载，file:// 或路径错 |
| 无声 | 未点雪花（无用户手势）；查 AudioContext state |
| 黑场后房屋不出现 | dip 回调里 enterStageMode 失败；看 console、GLB 是否已 parse |
| 受的苦乐和最终道不同 | 设计如此：peek vs 后再记 7s；见业力专题 |

控制台过滤 `[SixPaths] finalize` 可看最终 pathId、`pathTimeRatio`、`userBias`、`scores`。

## 5. 展场检查清单

1. HTTP(S) 打开，全屏。  
2. 点雪花后有 BGM、星空在动。  
3. 识能出房子（等预取）。  
4. 右上角面板在经文后出现，数字在变（或 mock）。  
5. 六道能出画面（用 `?path=` 六套都点一遍）。  
6. 饿鬼按 R 环会重置。  
7. 六道结束有黑场，「生」点云回来。  
8. 终章 Begin again 能回到开场（地址栏问号参数会消失）。  

外网不稳定时提前加 `?market=mock` 做保底链接，不要现场才发现 WS 挂了。

## 6. 推到 GitHub 之后观众还是旧的

Pages 从 `main` 分支发布。推送成功不等于立刻全球更新，等一两分钟。怎么用 GitHub Desktop 或 `git push`：[把改动放到网上](./专题-把改动放到网上.md)。然后：

1. 你改的那个 js 在 `app/index.html` 里 `?v=` 是否加了一？
2. 自己用无痕窗口打开 Pages 链接，不要用展场电脑昨天的标签。
3. 大文件 GLB 是否真的在仓库里（GitHub 网页能点开或显示体积）。

没改 `index.html` 只改了 `house-model-stage.js`：本地刷新可能因禁用缓存而能看见，Pages 上的观众仍拿 `v=120` 的旧副本。这不是 Git 没推上去。

调试参数不要写进二维码。观众带着 `?path=diyu` 进来会跳过整个十二因缘，直接地狱，这是制作后门不是作品。

## 7. 展场电脑不是你的笔记本

常见差异：没有 Python（观众不需要，他们打开 https）。你的笔记本预览成功，不等于展场那台能过墙访问币安和 cdnjs。开展前在**那台展场电脑、那个浏览器、那个网络**上用正式 Pages 链接走一遍，不要只在工作室的 localhost 签字。

展场建议用 Chrome 全屏（F11）。Win+D 会把窗口最小化露出桌面，尽量关掉通知、关掉会抢焦点的输入法候选窗。硬件加速在极少数核显上要开着，关了 WebGL 会软画卡成幻灯。

若必须离线演示：提前用 `?market=mock`，并接受房屋/饿鬼仍要 CDN。真离线需要把 three.min.js 和 p5.min.js 下载进仓库再改 `three-registry.js` 的 URL——这已经是改代码，不是改台词。开展前三天做，不要开展前三小时做。
