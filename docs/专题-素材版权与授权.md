## 2. 必须单独核的素材

### Mixkit 视频与 BGM

Mixkit 常见条款允许免费用于商业与非商业，且往往不强制署名；仍以 mixkit.co 当时页面为准。不要把文件改名后谎称自己拍摄/作曲。

### 字体

- `NITEMARE.TTF`：开场与台词。须核该字体作者的嵌入/再分发条款。
- `Pixelate-Regular.ttf`：仪表像素字。同名字体来源很多（有的只许个人用）。须对**这一份 TTF**核授权，不要假设 SIL OFL。
- `FZCAOYTJW(1).TTF`：**方正**类字体。方正字库对安装、嵌入网页、随软件分发通常有**单独授权**。把 TTF 放进 GitHub 公开仓库本身就可能越权。展出或开源前应：换成已获授权或开源中文字体，或取得方正授权并**不要**把未授权文件公开同步。

根目录若还有一份 `fonts/`，**正赛不会去读**。三套字都走 `app/styles/main.css` 的 `@font-face`（目录必须是 `assets/fonts/`）。`assets.config.js` 只写了 NITEMARE 和方正，且 NITEMARE 那条没有脚本用来加载字体；Pixelate **根本不在**配置文件里。

### 房屋 GLB

`assets/models/less_25mb.glb`。须确认模型来源（自建 / 购买 / 委托）是否允许在网页装置与公开仓库中使用。文档不代替购买合同。

### 六道图标与 line.webm

`realm-assets.config.js` 现在指向 `assets/logo/` 下的 **PNG**（`Deva.png` 等）和 `line.webm`。缺文件时面板有字母 / CSS 条 fallback，不是整场死。`assets/logo/README.txt` 仍写 AE 转 WebM 的旧流程（logo 也曾是透明视频），那是技术备忘，**不是**版权许可。若含购买的矢量或他人商标，另核。
