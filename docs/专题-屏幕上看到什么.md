# 专题：屏幕上看到什么、想改去哪

给**从来没写过程序**的人。上一篇教你如何打开页面；本篇对照屏幕：你看见的每一块字、每一段画面，实际写在哪个文件里。

不会改「房子怎么化成灰」「为什么进了修罗」也没关系。那些有专门专题，用到再打开。

先会打开： [从零在电脑上打开](./专题-从零在电脑上打开.md)。  
目录：[README](./README.md)。

---

## 0. 三个必须记住的规矩

1. **不要双击 HTML。** 用 localhost 打开。上一篇写过。
2. **屏幕上的英文不是都在同一个文件。** 改错文件、保存了、刷新了，画面也不会变。下面有表。
3. **改完某个 `.js` 文件，还要在 `app/index.html` 里找到对应那一行，把 `?v=` 后面的数字加一**，再刷新。否则电脑或网上还在用旧副本。怎么找：用编辑器打开 `app/index.html`，按 Ctrl+F，搜索你刚改的文件名（例如 `stages.config.js`），看到 `?v=32` 就改成 `33`。

不要动：`reference/` 里的图片和旧 Three（天道缺 `logo.png` 会黑屏且不报错）、`app/karma/six-paths-algorithm.js`（归道公式）、`app/effects/three-registry.js`（多份三维库开关）。

## 1. 从头到尾你会看见什么

点那颗会飞的光点（文案叫 comet / 文档里有时叫雪花）之后，大约十五段。数字是程序内部编号，观众看不到。

| 编号 | 你看见 | 要不要动手 | 大约多久 |
|---|---|---|---|
| 0 | 暗色星空、标题逐字出现，然后一颗光点飞 | 要点中光点或其拖尾附近约 50px，点屏幕别处不算。**最早约 3 秒**彗星才出现 | 等到你点 |
| 1 | 金刚经：左边英文、右边中文 | 可以点经文层跳过；不点也会自己走完 | 先等中文字体（通常很快，最多约 8 秒）再约 8 秒显现 + 约 0.15 秒尾巴 + 再停约 5 秒 |
| 2 | 一团会躲鼠标的粒子球 | 等约 4 秒出现中心提示，再点中心 | 等到点中 |
| 3 | 一座房子从中心长出来（识） | 可拖、可滚轮，不是过关条件 | 约 9.6 秒 |
| 4 | 房子化成许多小点（名色） | 同上 | 约 9.6 秒 |
| 5 | 六个圈（六入） | **必须点亮 6 个**，每点有一声 | 点完才走 |
| 6 | 触：靠近点云会有涟漪 | 不是过关点击 | 约 9.6 秒 |
| 7 | 受：房子按苦 / 乐 / 舍三种之一反应 | 底部台词三句里会出现一句 | 约 9.6 秒 |
| 8 | 爱：点像被弹簧拉住 |  | 约 8 秒 |
| 9 | 取：靠近会推开尘、离开还原 | 右上角仪表开始淡出 | 约 7.2 秒 |
| 10 | 角落一条进度条 0%→100% | 不用点 | 约 7 秒走完立刻结算，条再淡出约 0.4 秒，文案再停约 5 秒 |
| 11 | 全屏换成六道里的一套画面 | 天可移鼠标；人/畜可拖或滚；饿鬼可按 R；狱没有鼠标玩法（还会拦住滚轮） | 15 秒，然后先变全黑 |
| 12 | 黑场结束，点云以「生」的方式回来 |  | 约 6 秒 |
| 13 | 点云剥落、散掉（老死） |  | 约 11 秒 |
| 14 | 一句大字，稍后出现 Begin again | 点按钮整场重来 | 等到你点 |

右上角「業力計算系統」在经文结束后出现，取那段开始淡出，进度条起来时已经看不见。它是显示器，不是判决书。真正进哪一道在进度条走完时锁死，观众在第 11 段才看见结果。

底部大字是**叙事台词**。更淡、一闪一闪的是**操作说明**。两套不是一个文件，见第 2 节。

## 2. 屏幕上每一块字，改哪个文件

用编辑器「在文件夹中搜索」那句英文，也能找到。下表避免你改了分镜表却发现标题没动。

| 你看见的字 | 改这里 | 改完给 `index.html` 里哪一行 `?v=` 加一 |
|---|---|---|
| 开场大标题 *We have never existed independently.* | `app/ui/intro-controller.js` 里的 `INTRO_TEXT` | `intro-controller.js` |
| 浏览器标签页标题 | `app/index.html` 最上面的 `<title>` | 不用（改的是 html 自己） |
| *Click the comet to begin.* | `app/index.html` 里 `introCometHint` | 不用 |
| 金刚经中英文 | `app/index.html` 里 `sutraQuoteStage` 那几行 `<p>` | 不用 |
| 底部叙事台词（识、名色、触、爱、取、生、老死等） | `app/config/stages.config.js` 里各段的 `text: '...'` | `stages.config.js` |
| 「受」那句苦/乐/舍 | `app/config/paths.config.js` 的 `VEDANA_SUBTITLES` | `paths.config.js` |
| 六道那 15 秒同一句英文 | `app/config/paths.config.js` 的 `SIX_PATHS_SUBTITLES` | `paths.config.js` |
| 淡淡的操作说明（Hold and drag、按 R 等） | `app/ui/house-hint.js` 顶部的 `HOUSE_LINES` 等数组 | `house-hint.js` |
| *Touch the central singularity...* | `app/index.html` 里 `singularityHint` | 不用 |
| *KARMIC TOPOLOGY RESOLVED* 和下面那句 | `app/index.html` 里 `#karmaResolved` | 不用 |
| 终章大字 *No one stands alone...* | **`app/index.html` 里 `final-quote-text`**，不是分镜表 | 不用 |
| 按钮 *Begin again* / *Press to continue* | `app/index.html` 终章那一块 | 不用 |
| 六道 HUD「At this bound moment...」和下面那句 system loaded | **`app/ui/path-resolution-hud.js` 的 `show()`**（会覆盖 HTML 里的字） | `path-resolution-hud.js` |
| 六道 HUD 上的英文道名（Deva Realm 等） | `app/config/realm-assets.config.js` 的 `realm` | `realm-assets.config.js` |

终章那句在 `stages.config.js` 里也有一份，**节目里不会拿来显示**。只改分镜表，终章大字不会变。两处都想保持一致，就两处都改，以免以后有人看表时以为那是真字幕。

## 3. 我想改画面或时间，而不是改字

| 我想 | 去哪 | 专题 |
|---|---|---|
| 某一段太快/太慢 | `stages.config.js` 的 `durationMs`（毫秒，9600 就是 9.6 秒） | 舞台导演 |
| 开场几秒才能点光点、经文停多久 | `app/config/timing.config.js` | 开场字幕 |
| 淡淡的操作说明闪多快 | `styles/main.css` 里 `hintPulse 2.4s`（不是 `houseHintCycleMs`） | 开场字幕 |
| 换背景音乐 | `assets/audio/` 放 mp3，改 `assets.config.js` 的 `bgm` | 声音与必须存在的文件 |
| 换仪表像素字 | `styles/main.css` 里 Pixelate 的 `@font-face`（不在 `assets.config.js`） | 声音与必须存在的文件 |
| 换星空视频 | `assets/video/`，改 `assets.config.js` 的 `video.bg` | 同上 |
| 点云更青/更橙 | `house-model-stage.js` 顶部 `COL_HOUSE` | 房屋点云 |
| 光晕大小 | `ae-glow.js` 的 `DEFAULTS` | 辉光与黑场 |
| 六道用另一套特效 | `paths.config.js` 的 `effectId`（先问会程序的人） | 六道视觉、版本隔离 |
| 为什么进了这一道 | 不要先改公式。先读业力专题开头的人话 | 业力计算 |
| 展场平板/没网 |  | 展场与设备限制 |
| 推到网上还是旧台词 | 先 bump `?v=` 再 push | 把改动放到网上 |

完全不会程序时，优先只改**第 2 节表格里的字**和 `durationMs`。

## 4. 改完为什么没变化（按这个顺序）

1. 文件保存了吗？编辑器标签上不应再有圆点。
2. 改的是第 2 节说的那个文件吗？标题不在分镜表里。
3. 若改的是 `.js`：`app/index.html` 里对应 `?v=` 加了一吗？若改的是六道 / 触点球那份 `reference/...-embed.js`，还要去 `effect-registry.js` 给那条脚本 URL 加 `?v=`。
4. 浏览器地址是 `http://localhost:8080/...` 吗？不是 `file://`。
5. 硬刷新：Ctrl+F5。或再开一个无痕窗口贴同一地址。
6. 若看的是网上的 GitHub 链接：那是另一份文件，必须先 push。见 [把改动放到网上](./专题-把改动放到网上.md)。本机 localhost 才是你刚改的。

## 5. 后面那些专题要不要读

不必按目录从上读到下。

- **要自己改字、改秒数：** 本篇 + 从零打开，够了。开场字幕专题可以当「字还是没对上」时的说明书。
- **房子动得不对、光晕发糊：** 房屋点云、辉光。里面会有着色器，跳过公式、看「改哪个常量」即可。
- **天道黑屏、某一道白屏：** 声音与必须存在的文件、版本隔离、六道视觉。先查缺文件，不要改算法。
- 业力专题很长：**只需要知道「行情像公共心跳，鼠标像脾气，最后比谁分高」**。右上角那块板另见 [右上角仪表](./专题-右上角仪表.md)。公式和手算例子是给要调权重的人。
- **预览页、版权、发布：** 开展、公开仓库、或改完要验收时再读。

看不懂 `WebGL`、`CDN`、`r128` 时，去总览第 0 节词典；仍吃力就先不管，它们不妨碍你改一句英文。
