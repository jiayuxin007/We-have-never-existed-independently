# 专题：从零在自己电脑上打开

这篇给**从来没在电脑里敲过命令**的人。读完你应该能：打开作品、知道黑屏时先查哪三件事、知道「改台词」和「改画面算法」不是同一个文件夹。

不要求你会编程。要求你会：安装软件、复制粘贴一行字、用浏览器打开一个地址。

更完整的地图见 [总览](./总览.md)。对照屏幕改字见 [屏幕上看到什么](./专题-屏幕上看到什么.md)。排障见 [发布调试与排障](./专题-发布调试与排障.md)。

---

## 1. 先弄清你打开的是什么

这不是 Word 文档，也不是要安装的 App。它是一叠网页文件：HTML 负责骨架，JavaScript 负责「这一秒该干什么」，CSS 负责字号和位置，`assets` 里是视频、模型、字体、音乐。

浏览器（Chrome、Edge）会读这些文件，在你屏幕上画出来。所以：

- 没有「编译」「打包」「运行按钮」这种游戏引擎流程。
- 你的电脑必须让浏览器用 **http 地址**去读文件，不能像打开照片一样双击 `.html`。
- 双击打开时，地址栏会以 `file://` 开头。模型、字体、部分特效会被浏览器的安全规则拦住，表现为：没有房子、没有字、没有粒子，也不一定弹出醒目错误。

---

## 2. 你需要事先有的东西

| 东西 | 干什么 | 没有会怎样 |
|---|---|---|
| Chrome 或 Edge 新版本 | 画 WebGL、播视频 | 旧浏览器可能黑屏 |
| 项目文件夹（例如 `D:\NewProject`） | 里面有 `app/`、`assets/`、`reference/` | 缺模型或图片会在某一段挂 |
| Python 3 | 只用来执行一句「把这个文件夹暂时变成网站」 | 没有它，就没有 `localhost` |
| 终端 | Windows 上是 PowerShell 或「命令提示符」 | 你没法启动那句 Python |

不需要：Node.js、npm、Visual Studio、Xcode、账号、数据库。

**Python 怎么确认有没有：** 打开终端，粘贴：

```text
python --version
```

回车。若出现 `Python 3.x.x` 就行。若说找不到命令，去 python.org 安装，安装勾选 **Add Python to PATH**，然后关掉终端重开再试。有的电脑要用 `py --version`。

**终端在哪：** Windows 开始菜单搜 PowerShell。它是一个黑底白字窗口，只能打字，没有「打开文件」按钮。你要先「走进」项目文件夹，再执行命令。

---

## 3. 逐步：第一次打开作品

1. 确认文件夹里看得到 `app` 和 `assets`。若只有空目录，说明仓库没拷全（大文件 `less_25mb.glb` 尤其容易漏）。
2. 打开 PowerShell。输入（把路径换成你的真实路径）后回车：

```text
cd D:\NewProject
```

`cd` 的意思是「进入这个目录」。输错会报找不到路径。可以用 `dir` 看当前文件夹有没有 `app`。

3. 再粘贴这一行，回车：

```text
python -m http.server 8080
```

成功时窗口会停住，并写类似 `Serving HTTP on ... 8080`。**不要关这个窗口**，关了网站就停了。

嫌每次找 PowerShell 麻烦：仓库根目录有 `启动预览.bat`，双击它（仍然不要双击 html），等出现 Serving，再去 Chrome 打开下面的地址。

`8080` 是端口，可以理解成这台电脑上的门牌号。同一时间这个号只能被一个程序占用。若提示地址已被用，改成 `8081`，下面浏览器地址也改成 8081。

4. 打开 Chrome，地址栏输入（不要加空格）：

```text
http://localhost:8080/app/index.html
```

`localhost` 表示「这台电脑自己」。不是互联网上的某个网站。

5. 应看到暗色画面、标题逐字出现，随后有一颗会飞的光点。点它（或其拖尾附近约 50px），才有音乐、才开始记鼠标、才开始收比特币行情。点屏幕别处不算。光点大约 3 秒后才出现，出现前点了没反应。

打开之后下一篇请读 [屏幕上看到什么、想改去哪](./专题-屏幕上看到什么.md)，按画面找文件。

6. 看完后：回到 PowerShell 按 `Ctrl+C` 结束服务，然后可以关窗口。

线上观众不用做这些，他们打开 GitHub Pages 的 https 链接即可。本机这一套是给你改文件、立刻刷新看结果用的。要把改动给观众看见，读 [把改动放到网上](./专题-把改动放到网上.md)。

## 4. 打开之后你在看哪一层

屏幕从后到前（和 CSS `z-index` 一致，不是 HTML 书写顺序）：星空视频 → 特效层 → 右上角仪表（经文结束后）→ 底部台词 → **房屋画布**（透明处能看见下面的字和板；点和模型会挡住台词）→ 操作提示 → 自定义十字光标。完整表见 [开场字幕与界面](./专题-开场字幕与界面.md)。

不是每一段都有房屋。开场是 2D 光点；金刚经是纯文字；触点球是另一块 2D 粒子；六道是整屏换一套别人写好的视觉；最后是大字和按钮。

你若「改了代码没变化」：多半是浏览器还记着旧文件。见排障专题里的 `?v=`。本机也可以用无痕窗口再打开同一个 localhost 地址试一次。

## 5. 你想动字，还是动画面

完全不写代码也可以做的事：

- 先对照屏幕认路：[屏幕上看到什么、想改去哪](./专题-屏幕上看到什么.md)。**标题、金刚经、终章大字不在分镜表里。**
- 改底部叙事台词、改某一段几秒：打开 `app/config/stages.config.js`，改引号里的英文或 `durationMs`，保存后给 `index.html` 里 `stages.config.js?v=` 加一。
- 改苦乐舍三句话、六道那句固定台词：`app/config/paths.config.js`。
- 换一首 BGM：把 mp3 放进 `assets/audio/`，改 `assets.config.js` 里的 `bgm` 路径。

必须有人懂一点程序才能做的事：

- 点怎么抖、球怎么聚：房屋专题。
- 为什么天道黑屏：版本隔离专题（缺一张 png）。
- 为什么进了修罗不是人：业力专题。

不要在 `reference/` 里随便删图片。天道缺 `logo.png` 会黑屏且不报错，这是本项目最阴的坑之一。

## 6. 仍然打不开时的三步

1. 地址栏是不是 `http://localhost` 开头？若是 `file://` 或磁盘字母开头，回去第 3 节。
2. PowerShell 窗口是否还在跑、有没有红字？若端口占用，换端口。
3. 浏览器按 F12 打开「开发者工具」→ Network，刷新，看哪些文件是红色 404。把红色文件名记下来，对照 [声音与必须存在的文件](./专题-声音与必须存在的文件.md)。

## 7. 仍然害怕命令行时

可以请会电脑的人只帮你做一件事：双击仓库根目录的 `启动预览.bat`。以后不必找 PowerShell。窗口照样不能关。这不是给观众用的。

若 bat 没有、或你想自己建，内容为：

```bat
cd /d %~dp0
python -m http.server 8080
pause
```

改字仍然要用编辑器打开对应文件（见「屏幕上看到什么」那张表）。记事本可以，但注意保存为 UTF-8，否则中文注释会乱码。推荐 VS Code 或 Cursor 打开整个文件夹，左侧能看见 `docs` 和 `app`。
