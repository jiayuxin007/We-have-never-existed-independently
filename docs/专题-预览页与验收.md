# 专题：预览页与验收

本仓库**没有**单元测试、没有 CI 自动点鼠标。改完之后靠人眼和固定网址验收。  
`app/preview/` 与 `app/iris-preview.html` 是实验室，**不要写进观众二维码**。多数页写了「Preview only · 不接入正式流程」。句子不同、意思一样的：`mingse-preview.html` 是「老项目效果预览」，`bowl-swim-preview.html` 是「测试页 · 不接入主流程」，`frame-preview.html` 是「仅测试页，不接入正式流程」。`pie-chart-preview.html`、`progress-bar-preview.html` 页眉只写「样式预览」，**没**写那句免责，但仍是实验室，不进正式入口。

正式入口永远是 `app/index.html`（或 Pages 根跳转）。

---

## 1. 正式流程怎么抽查

本机 `http://localhost:8080/app/index.html` 加上参数（线上把主机换成 Pages 地址）：

| 目的 | 地址后缀 |
|---|---|
| 从某段开始 | `?debug=1&stage=N`（`debug=1` 不能省。识=3，房屋触=6，受=7，爱=8，业力条=10，六道=11，生=12） |
| 只看某一道 15 秒 | `?path=tian`（不必 `debug=1`；ren/xiuluo/chusheng/egui/diyu 或中文） |
| 受的苦/乐/舍 | 加 `&vedana=dukha` 等。单独写 vedana **仍从开场走**，只是到受时强制；要直接看受用 `?debug=1&stage=7&vedana=dukha` |
| 假行情 | `&market=mock`（Begin again 会丢掉这个参数） |
| 关仪表 | `&panel=0` |

完整走场仍要至少一次：点雪花 → 经文 → 触点球 → 识到取 → 条走完 → 六道 → 黑场 → 生/老死 → Begin again。抽查不能代替这一次。

控制台过滤 `[SixPaths] finalize` 可看到最终 pathId 和分数。天道黑屏先看 Network 的 `logo.png`。

## 2. 实验室页（改哪一块开哪一页）

路径相对仓库。本地需已开 `http.server`。

| 页 | 调什么 | 说明 |
|---|---|---|
| `app/preview/glow-preview.html` | AeGlow 阈值/半径/强度 | 勾选 Enable；空格可对比。调完把数字抄回 `ae-glow.js` DEFAULTS |
| `app/preview/mingse-preview.html` | 识/名色/触/受/爱等房屋 mode | 「十二因缘预览」；受三态、爱台词可在此对 |
| `app/preview/click-hint-gallery.html` | 触点球外观与奇点 | 与 Stage 2 同源画法 |
| `app/iris-preview.html` | 六道 15s → 黑场 → 生 | 六个页签是道名；验收 dip 是否叠帧。`app/preview/iris-preview.html` 只是跳转 |
| `app/preview/preta-text-preview.html` | 饿鬼白线/青线与字是否可读 | 明确写了不进正式流程 |
| `app/preview/pie-chart-preview.html` | 饼图四种 variant | 正式配置在 `chart.config.js` 的 orbital |
| `app/preview/frame-preview.html` | DataV 边框 | 面板壳 |
| `app/preview/progress-bar-preview.html` | 业力条样式 | 不是算法 |
| `app/preview/ending-restart-preview.html` | 终章按钮**样式** | 不是整场 `location.pathname` 重开 |
| `app/preview/bgm-lab.html` | 只听 BGM | 不走路程 |
| `app/preview/particle-lab.html` | 杂项粒子实验 | **不是**主流程六道 |
| `app/preview/swim-preview.html` / `bowl-swim-preview.html` | 房屋游动实验 | 未挂主分镜 |

改 Glow 不必走 10 分钟正片；改黑场用 iris-preview；改名色用 mingse-preview；改六道气质用 `?path=` 或 iris 页签。

## 4. 死代码，别改错文件

这些存在仓库里，**主流程 `index.html` 不跑它们**：

| 东西 | 说明 |
|---|---|
| `SIX_PATHS_ALGORITHM.run()` / CoinGecko | 遗留 REST，现用 Binance WS |
| `PATH_CONFIG[].condition`（算法文件里） | 硬门槛函数，`determinePath` 未调用 |
| `PATHS_CONFIG[].threeProfile` | 表里有，导演不读；profile 以 `EFFECT_DEFS` 为准 |
| `config/six-realms.config.js` 的 `SIX_REALMS` | `index.html` 会加载，**没有任何脚本读取**。协议代号以 `PATH_META.code` 为准，正式 UI 也不展示 |
| `blocking.type === 'sequence'` / `clicks` | 阻塞门实现了，分镜表没用 |
| `stages.config.js` 的 `collectInteraction` / `handledByMain` / `playNotesOnClick` | 只写在表上，主流程脚本不读 |
| `StageDirector.onSessionStart` | 函数在，从未调用（里面还有一遍采集 / 行情 / `NoteAudio.unlock`）。正赛这些都在 `main.js` 点雪花之后 |
| `shou:vedana` / `director:finished` / `stage:complete` / `stage:exit` | 导演会发，目前没有人听（`stage:enter` 才有提示和面板在听） |
| `TIMING_CONFIG.houseHintCycleMs` / `introCharAnimS` / `sutraCharAnimS` / `subtitleColorTransitionS` | 声明了，主流程 JS 没读。提示周期在 CSS `hintPulse 2.4s`；每个开场字母淡入是 CSS `0.05s`；台词颜色过渡是 CSS `#subtitleLayer` 的 `1.5s` |
| `KARMA_CHART_CONFIG.legendLayout` | 写了 `'pills'`，主面板不读。饼预览页自己画 pills |
| `effects/iris-wipe.js` | 旧转场；正赛是 `dip-fade.js` |
| `mouse-black-hole` | registry 有，`kind: 'unused'` |
| `reference/sketch2812705/` | 旧 p5 游动实验；主流程房屋不引用 |
| `particle-love/experimental-r128-wip/` | r128 移植失败，禁用 |
| `app/preview/**` | 实验室 |
| `assets/audio/sci-fi-score.mp3` | 不是 `assets.config.js` 的 bgm |
| 仓库根目录另放的 `fonts/` | 不是正赛路径；正赛在 `assets/fonts/`（含 Pixelate） |
