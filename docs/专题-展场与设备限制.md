# 专题：展场与设备限制

主流程按**一台带键鼠的电脑 + Chrome 全屏网页**设计，不是手机 App，也不是触摸墙默认方案。开展前用**展场那台机器、那个网、那个浏览器**走通，不要只在工作室笔记本上签字。

相关：[发布调试与排障](./专题-发布调试与排障.md)、[声音与必须存在的文件](./专题-声音与必须存在的文件.md)。

---

## 1. 输入：鼠标，不是手指

采集器和房屋交互听的是 pointer / click / wheel。提示文案写的是 drag、scroll、click、按 R。

- 没有单独的触摸手势（无双指缩放适配、无「点按代替悬停」）。
- 触点球要「靠近再点中心」；手机上没有稳定悬停，4 秒后的奇点很容易点不中。
- 畜生道自带 OrbitControls 拖转，触屏行为因浏览器而异，未验收。
- 自定义十字光标在部分触摸设备上不出现或对不齐。

**结论：请按桌面展项布置。** 若必须用平板，只能当风险实验，不能当交付标准。竖屏、刘海、浏览器底栏都会切坏全屏图层。

键盘：饿鬼 R 重置环；畜生空格暂停已被拦截。不要指望全键盘操作。

## 2. 机器要能画画

房屋点云 + 六道里多套 **GPGPU**（在显卡上用纹理存几万到几十万粒子）：

| 段 | 负担 |
|---|---|
| 房屋点云 + Glow | 中等；核显勉强，独显轻松 |
| 修罗 4D 噪声网格 | 第一次编译约 1～1.3 秒，之后还好 |
| 天 / 人 / 狱 | GPGPU + 后处理，独显更稳 |
| 畜生 Hyper Mix | hash 里 `amount=524k`，**五十万级**粒子 + DOF/Bloom/运动模糊，最吃显卡 |

浏览器对 WebGL 上下文数量有上限（常见大约十来个）。人道/地狱/畜生 dispose 时 `forceContextLoss` 就是在还上下文。预览时不要对同一道狂刷新几十次。

建议展场：近几年的独立显卡或较新的核显（Intel Xe / 苹果 M 系列）、8GB 以上内存、外接或笔记本电量插着。省电模式会把 GPU 降频，六道会掉帧。Chrome 设置里不要关「硬件加速」。

分辨率：按 1920×1080 全屏调过。4K 上 `pixelRatio` 上限 2，仍会更卡。能用 1080p 展就用 1080p。

## 3. 网络三件事，缺一可能「像程序坏了」

1. **页面自己：** GitHub Pages 或本地 http。`file://` 禁止。
2. **CDN：** `three.min.js` 和 p5 走 cdnjs；GLTFLoader、OrbitControls 走 jsDelivr。墙了或断网（墙**任意一家**）：房屋和饿鬼挂；人道等旧 Three 在仓库里，仍可能出。
3. **币安 WebSocket：** `btcusdt@ticker`。墙了：仪表数字停、归道缺市场项。保底 `?market=mock`（假盘，不能当共业解释）。**连上后若中途断线，不会自动重连**，数字会停在最后一包；要刷新或换 mock 链接。

Begin again 会清掉 URL 参数。把 `?market=mock` 印进观众二维码时，第一场是假盘，点按钮重来的第二场会去连真币安。网不稳时请工作人员重新打开带参数的链接。

意大利/欧洲展场一般这三条都通。在部分网络环境（含部分中国宽带）CDN 或币安会失败。开展前在现场 Wi‑Fi 打开正式 https 链接测：星空、识的房子、点雪花后面板数字是否在变。

完全离线：要把 r128 和 p5 改成本地文件（改 `three-registry.js`），并永远 mock 行情。这是改代码，开展前三天做。

## 4. 浏览器与系统

- 推荐 **Chrome 或 Edge 最新稳定版**，F11 全屏。Safari / Firefox / 平板浏览器**没有当交付标准验收**。
- 关掉通知、自动更新弹窗、输入法候选窗抢焦点。
- Win+D 会露桌面，尽量锁键盘或说明「不要按 Windows」。
- 标签切到后台会暂停 `requestAnimationFrame`，观众以为死了。展场不要让人把窗口缩到托盘。
- 展场账号不要开会注入广告的「清理大师」。

声音：系统音量、Chrome 标签是否静音、必须先点雪花（自动播放策略）。详见声音专题。

## 5. 隐私（展方若问「有没有上传观众」）

- **鼠标、点击、滚轮**只在这台电脑的浏览器内存里累加，进度条结束用于本地算道。没有自己的后台服务器去收这些数。
- **币安**只收公开的 BTCUSDT 行情，与观众身份无关。
- **localStorage** 会写入 `sixPathsResult` 和 `sixPathsResultTime`（JSON）。**主流程从不读回来**（没有 `getItem`）。导演切六道用的是这一次打开页面的内存结果。Begin again 跳到无参数的 pathname 后会重算。旧 JSON 可能留在这台电脑的浏览器里，直到有人清站点数据。不含姓名、不含账号。
- 没有 Cookie 追踪、没有登录、没有摄像头、没有麦克风（Web Audio 只出声）。

若展方要求「不留任何本地痕迹」，需要改代码去掉 `localStorage.setItem`，并说明刷新前仍会短暂存在内存。当前没做「无痕模式强制」。

## 6. 开展当天最短清单

1. 正式 https 链接，无 `?debug`、无 `?path=`。  
2. 键鼠可用，全屏，硬件加速开。  
3. 点雪花 → 有 BGM、有星空。  
4. 识能出房子（等数秒加载）。  
5. 经文后面板数字在变（否则 mock 或查网）。  
6. `?path=` 六套在**展场电脑**上各看一次（制作日，不要印在观众二维码上）。  
7. 终章 Begin again 能重来。  
8. 备一条 `?market=mock` 私链，仅网挂时用。
