# 专题：声音与必须存在的文件

两个容易被忽略、却能让整场「看起来像坏了」的东西：声音策略，以及磁盘上少一个文件。

---

## 1. 为什么必须先点雪花才有音乐

浏览器禁止网页一打开就出声（防广告）。本项目 BGM 是 `<audio id="ambientAudio">`，`autoplay` 为 false，音量 0.35，循环。正赛里 `BgmController.startLoop()` 只在雪花点击这个**用户手势**之后调用 `audio.play()`。调试跳段（`?debug=1&stage=N` 且 N>0，或单独 `?path=`）也会在开机时 `startLoop()`，没有手势，浏览器常会拦，这不代表正赛坏了。若 play 被拒，catch 掉并打 `[Bgm] play failed`，画面照走，只是静音。

文件：`assets/audio/xanthos.mp3`（Mixkit，Xanthos / Eugenio Mininni）。路径写在 `config/assets.config.js` 的 `bgm`。换曲：换成你的 mp3，改这一条路径，bump `assets.config.js?v=` 与 `bgm-controller.js?v=`。

不要指望后台标签里音乐会一直响：有的浏览器会暂停不可见标签的媒体。

---

## 2. 六入的六个音不是 mp3 主路径

`ui/note-audio.js` 用 **Web Audio API 现场合成**：

- 频率（Hz）：261.63，293.66，329.63，392.00，440.00，523.25（C4 五声再回到 C5）
- 两个振荡器：正弦 + 频率 ×2.002 的三角波（轻微失谐，不那么电子死）
- 每个音再叠一个低八度、更弱的正弦
- 低通从 2200Hz 滑到约 680Hz
- delay 0.28 秒，反馈 0.32，主音量 0.22

`unlock()` 同样要在用户手势里 `AudioContext.resume()`，雪花点击时会做。配置里也列了 `note1.wav` … `note6.wav`，当前主流程走合成器。六入点亮时由 `house-model-stage.js` **直接** `NoteAudio.playNote(index)`。`blocking:click-progress` 是给「任意点击计数」那种阻塞用的，主流程六入不是这种，改那条事件不会改六入的声音。`stages.config.js` 里的 `playNotesOnClick` **没有任何脚本读取**，改它无效。

没有扬声器时，六入「过关」仍然成立，只是没有反馈音。

---

## 3. 饿鬼按 R 不是声音

R 重置粒子环。S 会触发浏览器下载一张图（调试残留）。不要以为 S 是音效。

## 5. 预加载在 HTML 里写了什么

`app/index.html` 的 `<head>`：

- preload NITEMARE 字体
- preload GLB（`as=fetch`）

开场 2 秒锁点击，就是给 GLB 预取留时间。网慢时仍可能看到房屋 loading。HTML 的 preload 和 `HouseModelStage.prefetchModel()` 的 `fetch` 是两次请求；第二次通常打到浏览器缓存，再 `GLTFLoader.parse` 这份 ArrayBuffer，后面不再走网络。

## 6. 换素材的最小动作

1. 把文件放进对应文件夹，文件名尽量英文、别带空格。根目录那份 `fonts/` **不是**正赛路径，TTF 必须在 `assets/fonts/`，与 CSS 一致。
2. 换 BGM / 星空 / 模型：改 `assets.config.js`。换 Pixelate：改 `styles/main.css` 的 `@font-face`。换面板 logo：`realm-assets.config.js`。
3. 改了 `.js` 就给对应 `<script src="…?v=N">` 加一；改了 CSS 就给 `main.css?v=` 加一。换 BGM 还要 bump `assets.config.js` 与 `bgm-controller.js`。
4. 硬刷新。天道换图后用 `?path=tian` 直接验证，省得走完全场。

GLB 过大时 GitHub 可能警告；本仓库已经在用约 25MB 以下的模型名。再大要考虑压缩网格或 Git LFS，否则 Pages 下载会让「识」无限转圈，被误判为程序错误。

## 7. 展场音频检查（不会代码也能做）

带一副耳机插在展场电脑上走一遍：

1. 没点雪花前应静音。若一进页就出声，说明有人改过 autoplay，部分浏览器仍会拦，行为不一致。
2. 点雪花后 1 秒内应有 BGM。没有：先看系统是否静音、浏览器标签是否静音（标签页喇叭图标）、文件是否 404。
3. 六入六点应有六个不同音高。没有 BGM 但有点声音：BGM 路径坏了，合成器是好的。反过来只有 BGM 没有点音：AudioContext 没 resume，或提示音量被系统压掉。
4. 六道段 BGM 仍在底下，没有换轨。饿鬼按 R 不应出声。
5. 终章 Begin again 之后应再次静音直到再点雪花。按钮会清掉 URL 参数后重开。若重开后自动响，是浏览器记住了用户手势，可以接受；若重开后死寂，再点一次雪花。

不要在展场用 `file://` 测声音：自动播放策略和字体、模型是同一类限制，结果不可信。

换 Mixkit 以外的音频、或要把仓库公开：先读 [素材版权与授权](./专题-素材版权与授权.md)。方正字体与 Mixkit 不是「放进 Git 就等于可任意再分发」。
