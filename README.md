# We have never existed independently.

全屏网页装置。观众入口：[`app/index.html`](app/index.html)。  
线上：https://jiayuxin007.github.io/We-have-never-existed-independently/

本地必须用 HTTP（不要双击 HTML）。可双击仓库里的 `启动预览.bat`，或：

```bash
python -m http.server 8080
```

打开 `http://localhost:8080/app/index.html`。
