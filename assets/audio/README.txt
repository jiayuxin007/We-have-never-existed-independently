Background music (BGM)

Place a legally obtained copy of Harry Gregson-Williams — “Mars”
(from The Martian: Original Motion Picture Score, 2015) at:

    assets/audio/mars.mp3

Playback: starts when the user clicks the snowflake cursor, then loops
for the rest of the experience.

This project does not ship the commercial recording. Buy/download from
an official store, then drop the file at the path above.

Official album (examples):
- Apple Music / iTunes: The Martian (Original Motion Picture Score)
- Amazon / TIDAL: same album, track 1 “Mars”
